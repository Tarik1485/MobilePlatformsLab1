Мета роботи

Ознайомитися з основами Dart, навчитися працювати зі змінними, функціями, класами, колекціями та асинхронним програмуванням. Реалізувати допоміжні класи, обробку даних і модульні тести.

Виконані завдання

Завдання 1. Змінні та типи даних

Файл: bin/task1_variables.dart

Оголошення змінних і використання основних типів Dart.

Робота з рядками, числами та логічними значеннями.

Колекції та null safety.

Завдання 2. Функції

Файл: bin/task2_functions.dart

Створення та виклик функцій.

Передавання аргументів і повернення результатів.

Реалізація обчислень та обробки тексту.

Використання функціональних операцій над колекціями.

Завдання 3. Об'єктно-орієнтоване програмування

Файл: bin/task3_classes.dart

Реалізовано моделі університетської системи:

Student — студент, оцінки, навички та курси.

Course — навчальний курс і його характеристики.

Professor — викладач.

University — керування студентами, курсами та викладачами.

Person — абстрактний базовий клас.

Завдання 4. Колекції та обробка даних

Файл: bin/task4_collections.dart

Робота зі списками List, множинами Set і словниками Map.

Фільтрація, сортування та групування даних.

Обчислення середніх значень і статистики.

Робота з CSV-файлом students.csv.

Завдання 5. Асинхронне програмування

Файл: bin/task5_async.dart

Використання Future та async/await.

Паралельне виконання асинхронних операцій.

Робота з Stream.

Збереження та читання JSON-даних.

Обробка помилок і тайм-аутів.

Встановлення та запуск

Потрібен встановлений Dart SDK.

Отримання залежностей:

dart pub get

Запуск окремих завдань:

dart run bin/task1_variables.dart
dart run bin/task2_functions.dart
dart run bin/task3_classes.dart
dart run bin/task4_collections.dart
dart run bin/task5_async.dart

Тестування

Запуск усіх модульних тестів:

dart test

Висновок

Під час виконання практичної роботи було опрацьовано основні можливості мови Dart:
 типи даних, функції, об'єктно-орієнтоване програмування, колекції та асинхронність.
 Створено моделі університетської системи, утиліти для обчислень і обробки даних, а також модульні тести для перевірки працездатності реалізованих компонентів.
