Практична робота №5 — Розробка віджетів у Flutter

Загальна інформація

Дисципліна: Програмування для мобільних платформ
Тема: Віджети і компоненти у Flutter
Мета: Навчитися створювати власні віджети, працювати з моделями даних, оформленням інтерфейсу, анімаціями та навігацією між екранами.

Опис проєкту

Mobile Widgets App — навчальний Flutter-застосунок, який демонструє створення повторно використовуваних компонентів і побудову багатосторінкового інтерфейсу.

Реалізовані можливості

Головний екран із власними кнопками.

Каталог товарів у вигляді карток.

Додавання товарів до кошика та лічильник кошика.

Екран профілю користувача.

Нижня навігація між трьома екранами.

Власний віджет кнопки з різними стилями.

Власні віджети профілю та картки товару.

Анімований лічильник.

Моделі User і Product із методами copyWith, toJson та fromJson.

Світла тема оформлення Material 3.

Запуск проєкту

Переконайтеся, що встановлено Flutter SDK.

flutter pub get
flutter run -d chrome

Перевірка якості

Аналіз коду:

flutter analyze

Запуск тестів:

flutter test

Висновок

Під час виконання практичної роботи створено Flutter-застосунок із повторно використовуваними віджетами, моделями даних, анімованими елементами та навігацією між екранами.
 Отримано практичні навички організації структури Flutter-проєкту, тестування компонентів і використання Material Design 3.
