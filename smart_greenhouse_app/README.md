Практична робота 8. Асинхронність у Dart

Тема

Асинхронне програмування у Flutter: Future, Stream, FutureBuilder і StreamBuilder.

Варіант 1

Smart Greenhouse Monitoring — моніторинг розумної теплиці.

Мета роботи

Навчитися працювати з асинхронними операціями у Dart, отримувати дані паралельно, обробляти помилки та відображати дані в реальному часі.

Опис застосунку

Застосунок імітує систему моніторингу розумної теплиці. Він відображає показники температури, вологості та освітленості, а також дозволяє призупиняти й відновлювати оновлення.

Реалізовані можливості

Паралельне завантаження даних за допомогою Future.wait.

Обмеження часу завантаження через timeout.

Використання FutureBuilder для початкового завантаження.

Використання StreamBuilder для відображення поточних показників.

Автоматичне оновлення даних приблизно кожні 1,5 секунди.

Обробка помилок завантаження та датчиків.

Можливість повторного завантаження даних.

Пауза й відновлення оновлень.

Контроль допустимих меж показників.

Звільнення ресурсів і закриття потоку під час завершення роботи екрана.

Структура проєкту

lib/main.dart — точка входу в застосунок.

lib/models/sensor.dart — модель датчика.

lib/models/greenhouse_data.dart — модель даних теплиці.

lib/services/greenhouse_service.dart — сервіс завантаження й оновлення даних.

lib/screens/greenhouse_screen.dart — інтерфейс користувача.

test/widget_test.dart — тест запуску застосунку.

docs/ — скриншоти роботи програми.

Запуск

flutter pub get
flutter run -d windows

Перевірка

flutter analyze
flutter test

Висновок

Під час виконання практичної роботи створено Flutter-застосунок для моніторингу теплиці. Реалізовано асинхронне завантаження даних, роботу з потоками, оновлення показників у реальному часі, обробку помилок і керування оновленнями.
